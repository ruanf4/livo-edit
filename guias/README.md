# Gabarito Livo Edit para usar pelo celular

Escolha o estilo pelo nome e peça a edição em linguagem natural no ChatGPT Work,
com o plugin Livo Edit instalado e as ferramentas de vídeo disponíveis.

- [Gabarito completo em PNG](gabarito-estilos-livo-edit.png)
- [Pacote de imagens para compartilhar](gabarito-livo-edit-celular.zip)
- [1 · Headlines](livo-edit-celular-01.png)
- [2 · Modelos Livo](livo-edit-celular-02.png)
- [3 · Legendas clássicas](livo-edit-celular-03.png)
- [4 · Pedidos pelo chat](livo-edit-celular-04.png)

As prévias são frames renderizados pelos componentes do editor, usando as fontes
da publicação. Não são vídeos: os modelos marcados como animados têm movimento
no resultado final. O guia inclui os seis presets Livo, os seis modelos clássicos
e cinco estilos de headline. Cores e exemplos servem como referência; peça os
ajustes para o seu próprio vídeo.
